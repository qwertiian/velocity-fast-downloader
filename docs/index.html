Built from scratch for reliability first, with speed where your connection and the server allow it.

🚀

Multi-connection

Files are split into parts that download in parallel. Finished connections help the slow ones until the end.

⏸️

Pause & resume anytime

Close the app, lose Wi-Fi or restart your PC. Velocity continues exactly where it stopped.

🔁

Self-healing

Dropped connections and server errors are retried automatically, and it backs off politely when a server asks.

🛡️

Safe by design

Never mixes data from a changed file, verifies checksums, and never runs downloads on its own.

🎚️

Questions

More in the full FAQ.

Is it really free?

Yes. No price, no ads, no premium tier and no account.

Windows says "Windows protected your PC". Is it safe?

That only happens with the direct installer, which isn't code-signed yet. Install from the Microsoft Store to avoid it, or click More info → Run anyway. To be certain your file is genuine, compare its SHA-256 with SHA256SUMS.txt on the release page.

Will every download be faster?

Not always. Multiple connections help most with distant or busy servers. Nothing can exceed your internet plan or what the server allows. Velocity's other big win is reliability: downloads don't start over.

Does it download streaming videos (YouTube, Netflix…)?

No. Velocity downloads direct file links and respects DRM and website restrictions.

Is there a browser extension?

Coming soon to the Chrome Web Store, Edge Add-ons and Firefox Add-ons. With it, downloads you click open in Velocity. Until then, copy a download link and Velocity pops up and offers to download it.

Can it speed up Steam or Epic Games downloads?

No. Those launchers use their own signed-in, encrypted download systems that no separate app can take over. Tips that do help are in the FAQ.

Mac or Linux?

Planned. Watch the GitHub repository for releases.
